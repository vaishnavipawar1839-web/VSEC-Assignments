# Assignment 2 – Git Session

## Aim
To study and perform basic Git commands.

## Introduction
Git is a distributed version control system used to track changes in files and manage source code.

## Git Working Areas
1. **Working Directory:** Contains project files.
2. **Staging Area:** Contains changes prepared for commit.
3. **Repository:** Stores committed changes and project history.

## Basic Git Commands

| Command | Purpose |
|---|---|
| `git init` | Creates a new repository |
| `git clone` | Copies a remote repository |
| `git status` | Shows the status of files |
| `git add` | Stages changes |
| `git commit` | Saves staged changes |
| `git push` | Uploads commits to GitHub |
| `git pull` | Downloads and integrates remote changes |
| `git branch` | Lists branches |
| `git switch` | Switches branches |
| `git merge` | Combines branches |
| `git stash` | Temporarily saves uncommitted changes |
| `git log` | Shows commit history |
| `git reset` | Resets staging or moves the branch pointer |
| `git restore` | Restores file contents or unstages files |
